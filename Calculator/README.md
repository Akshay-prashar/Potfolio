# Calculator

A functional web-based calculator with a clean, modern UI.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use

Open `Calculator.html` in any web browser.

## Features

- Basic arithmetic operations (+, −, ×, ÷)
- Clear and equals functionality
- Responsive button layout
- Clean dark-themed interface

## Project Structure

```
Calculator/
├── Calculator.html           # Main HTML page
├── Calculator_style.css      # Styling
└── Calculator_script.js      # Calculator logic
```
