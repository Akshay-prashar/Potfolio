# Netflix Clone

A frontend clone of the Netflix web interface built with HTML and CSS.

## Tech Stack

- HTML5
- CSS3

## Preview

Open `Netflix.html` in any web browser to view the clone.

## Features

- Netflix-style hero banner with sign-up CTA
- Feature sections with embedded video previews
- FAQ accordion section
- Responsive dark-themed design matching Netflix's aesthetic

## Project Structure

```
Netflix/
├── Netflix.html          # Main HTML page
├── Netflix.css           # Styling
└── Netflix_Assets/       # Images, videos, and logos
```
