## Getting Started

Each project folder contains its own `README.md` with setup instructions and a `requirements.txt` (for Python projects).

### Portfolio Website
The landing page (`index.html`) is at the root. All other portfolio pages live in the `Potfolio/` folder.

### Python Projects
```bash
cd <project-folder>
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
python main.py           # or see project README for specifics
```

### Frontend Projects (Amazon, Netflix, TicTacToe, Calculator)
Simply open the `.html` file in your browser — no build step required.
