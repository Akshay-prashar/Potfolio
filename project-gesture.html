Gesture Control System

A modular, real-time hand gesture recognition system that translates webcam input into OS-level commands — enabling hands-free control of any application.

Role Sole Developer
Type Real-Time CV System
Stack Python, OpenCV, MediaPipe

Tech Stack

Python 3.x OpenCV MediaPipe PyAutoGUI NumPy

Links

Source Code

Problem

Traditional input devices — mouse, keyboard, touchpad — require physical contact. For scenarios like presentations, accessibility needs, or experimental interfaces, there is a gap for natural, contactless interaction with a computer.

Existing gesture solutions are either hardware-dependent (Leap Motion), expensive, or lack the modularity to adapt across different applications and contexts.

Solution

Built a Python-based gesture control pipeline that uses a standard webcam to track hand landmarks in real-time via MediaPipe, interprets configured gestures, and dispatches system-level commands through PyAutoGUI.

The system uses a modular profile architecture — each application (Chrome, VLC, system controls) gets its own gesture mapping that can be swapped at runtime without restarting the pipeline.

Key Features

Real-Time Hand Tracking

21-point hand landmark detection at 30+ FPS using MediaPipe's optimized pipeline.

Context-Aware Profiles

Separate gesture mappings for system control, Chrome browser, VLC media player, and custom applications.

Gesture Confidence Scoring

Filters out jittery or accidental gestures using rolling confidence windows to prevent false triggers.

Cursor Edge Reach

Soft clamping and dead zones ensure the cursor can reach all screen edges naturally.

Modular Architecture

Clean separation of detection, gesture recognition, and action dispatch — easily extensible for new gestures and applications.

Challenges

Latency: Achieving smooth cursor movement required decoupling the detection loop from the rendering loop and using exponential moving averages for FPS stabilization.

False positives: Random hand movements triggered unintended commands. Solved by implementing a confidence threshold system with temporal smoothing.

Edge detection: Mapping hand positions to full screen coordinates with dead zones at edges required careful calibration of the coordinate transform pipeline.

Outcome

A fully functional hands-free control system that runs on any Windows laptop with a webcam. The modular design makes it a foundation for future extensions — including integration with voice control and brain-computer interfaces.
