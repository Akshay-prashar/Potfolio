# Tic Tac Toe

A classic Tic Tac Toe game played in the browser with sound effects and animated game-over state.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Play

Open `TicTacToe.html` in any web browser.

## Features

- Two-player turn-based gameplay (X vs O)
- Win detection with visual highlighting
- Sound effects for turns, game over, and reset
- Animated game-over GIF overlay
- Reset button to start a new game

## Project Structure

```
TicTacToe/
├── TicTacToe.html        # Main HTML page
├── TicTacToe.css         # Styling
├── TicTacToe.js          # Game logic
└── TicTacToe_Asset/      # Sound effects and images
```
