# Amazon Clone

A frontend clone of the Amazon web interface built with HTML and CSS.

## Tech Stack

- HTML5
- CSS3

## Preview

Open `Amazon.html` in any web browser to view the clone.

## Features

- Responsive Amazon-style navigation bar with search functionality
- Product grid layout with category boxes
- Hero banner section
- Footer with multi-column links

## Project Structure

```
Amazon/
├── Amazon.html          # Main HTML page
├── Amazon.css           # Styling
└── Amazon_Assets/       # Images and logos
```
