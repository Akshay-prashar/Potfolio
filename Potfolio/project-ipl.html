IPL Winner & Score Prediction

A contextual prediction engine that forecasts IPL match winners and final innings scores ball-by-ball, using engineered features and XGBoost models served via FastAPI.

Role ML Engineer
Type Predictive Analytics
Stack Python, XGBoost, FastAPI

Tech Stack

Python 3.x XGBoost Pandas & NumPy Scikit-learn FastAPI Joblib Google Colab

Links

Source Code

Problem

Existing IPL prediction models produce a single pre-match prediction that ignores the evolving match context. During a run chase, win probabilities remain static despite dramatic changes in required run rate, wickets in hand, and batting partnerships.

The result: a 99% win-probability bias that fails to capture the actual dynamics of live cricket — rendering predictions useless for real-time commentary or betting analysis.

Solution

Built a two-model prediction system: one for match winner probability and one for final innings score estimation. Both models ingest ball-by-ball contextual features — including target score, required run rate, current run rate differential, and partnership data.

The models are trained on historical IPL data with extensive feature engineering, then served via a FastAPI inference endpoint that accepts live match state and returns calibrated predictions.

Key Features

Ball-by-Ball Context

Features like required run rate, wickets remaining, and batting partnership duration update every delivery.

Dual-Model Architecture

Separate XGBoost classifiers for winner prediction and score regression, each optimized for their specific task.

FastAPI Inference

Production-ready API endpoint that accepts match state JSON and returns predictions in milliseconds.

Feature Engineering Pipeline

Automated feature extraction from raw ball-by-ball data, including venue encoding, team strength metrics, and momentum indicators.

Challenges

99% bias problem: Initial models showed extreme win probability bias during second innings. Solved by introducing target_score and required_run_rate as first-class features.

Data imbalance: Winning team data is inherently imbalanced across venues and seasons. Applied SMOTE and stratified cross-validation to maintain prediction stability.

Outcome

A deployable, real-time prediction engine that reacts to match dynamics rather than static pre-match data. The system provides probability shifts that actually reflect game momentum — useful for commentary tools, fan engagement platforms, and analytical dashboards.
