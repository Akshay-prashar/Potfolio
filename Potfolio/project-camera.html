Wireless Camera Stream

A high-performance phone-to-PC camera streaming solution using WebRTC over local WiFi — zero install on the phone, ultra-low latency desktop viewer.

Role Systems Developer
Type Real-Time Streaming
Stack Python, WebRTC, PyQt5

Tech Stack

Python 3.x WebRTC / aiortc aiohttp PyQt5 PyAV

Links

Source Code

Problem

Using a phone as a wireless webcam typically requires installing third-party apps on both devices, dealing with USB drivers, or accepting high latency and unreliable connections. Existing solutions like DroidCam require app installations, and browser-based alternatives suffer from encoding lag.

Solution

Built a two-part system: a lightweight web page served over local WiFi that accesses the phone's camera via the browser (zero install required), and a native Python desktop viewer using PyQt5 that receives the stream via WebRTC for ultra-low latency display.

The signaling server runs on the PC using aiohttp, handling WebRTC offer/answer exchange. The actual video stream uses peer-to-peer WebRTC — bypassing server encoding entirely for minimal latency.

Key Features

Zero-Install Phone Side

Phone opens a local URL in any browser — no app installation needed. Works on any phone with a modern browser.

WebRTC Peer-to-Peer

Direct video stream between phone browser and PC viewer — no server-side re-encoding, resulting in sub-100ms latency.

Native Desktop Viewer

PyQt5-based viewer with smooth frame rendering, FPS overlay, and window controls.

AI Vision Integration

Extended with YOLOv8n real-time object detection and centroid-based tracking with persistent IDs.

Challenges

Frame jitter: Initial implementation showed visible frame drops. Solved by implementing exponential moving average FPS stabilization and decoupling the render thread from the decode thread.

Cross-device WebRTC: Different phone browsers handle WebRTC capabilities differently. Required careful negotiation of codecs and ICE candidates for reliable cross-device connections.

Outcome

A plug-and-play wireless camera solution that runs on any WiFi network without installing anything on the phone. The system achieves low latency suitable for real-time use cases — from video calls to AI-powered computer vision experiments.
